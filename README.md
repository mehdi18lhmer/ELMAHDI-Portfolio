## 📦 Quick Start
```bash
# Clone the repository
git clone https://github.com/mehdi18lhmer/ELMAHDI-Portfolio.git
cd ELMAHDI-Portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```
Open `http://localhost:5173` in your browser to explore the portfolio.
